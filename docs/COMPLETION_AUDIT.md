# AutoForge 완성도 감사

기준일: 2026-07-18
검증 명령: `npm run check`

## 판정 기준

- **검증 완료**: 저장소 안에서 동작하며 자동 테스트 또는 전체 여정 E2E로 재현된다.
- **MVP 완료**: 안전한 결정론적 모델과 교체 가능한 실행 계약이 동작한다. 산업용 해석기나 설비의 실제 결과를 뜻하지 않는다.
- **외부 연동 필요**: 소프트웨어 계약과 게이트는 있으나 현장 바이너리, 장비, 인증기관 또는 사업 데이터가 필요하다.

## 제품 표면

- Project Studio, Concept Lab, Architecture Designer, Simulation Hub, Optimization Center
- Robot Lab, Digital Twin, BOM/Cost, Mission Control, Agent Center, Governance Center, Platform Ops
- BOM/Cost는 설계별 제조성 평가, 실제 비용 롤업, 조립 스테이션, 공급 위험, 공급사 품질·납기와 검증된 대체 후보를 시각화하고 실제 BOM CSV를 생성한다.
- Digital Twin은 최신 텔레메트리, 센서 스트림, 실물시험, 오차 등급, 모델 bias·신뢰도 보정 계보를 하나의 Sim-to-Real 작업공간으로 제공한다.
- Simulation Hub는 프로젝트·설계별 4종 해석 실행과 실제 결과 증거 인스펙터를 제공하며, 고정 인사이트나 가짜 실행 상태를 사용하지 않는다.
- Project Studio는 조직 내 고유 코드로 격리 프로젝트를 생성하고, 실제 프로젝트 선택기·최신 설계 성능·에이전트 상태·후보 revision·검증 통계·프로젝트별 보고서를 제공한다. 선택 컨텍스트는 목표, 콘셉트, 아키텍처, 시뮬레이션, 최적화, 로봇, Digital Twin, BOM과 거버넌스에 전달되며 쓰기 작업은 명시적 프로젝트·설계 ID를 요구한다.
- 로그인, 조직별 사용자/역할 관리, 승인 알림, PDF 보고서, ZIP 설계 릴리스
- 파라메트릭 슬라이더, 컴포넌트 추가·드래그·revision 저장이 가능한 아키텍처 그래프, 차량 SVG 설계도, 비교 차트와 상태 시각화

## 운영 품질 증거

- 단위·모듈·API 계약 테스트 147개
- 인증 운영 모드의 실행 스트림은 URL에 토큰을 노출하는 `EventSource` 대신 Authorization 헤더를 지원하는 Fetch 스트림과 부분 프레임 안전 SSE 파서를 사용한다.
- 운영 서버가 `/api/openapi.yaml`에서 OpenAPI 3.1 계약을 제공하며, 요구사항 초안·승인·개정·기준선·증거 검증 경로는 구현과 문서의 동기화를 자동 검사한다.
- 프로덕션 인증 모드 API 전체 여정 E2E 1개
- 데스크톱·모바일 Chromium 브라우저 여정 4개(CI 필수 실행; 로컬은 Playwright 시스템 라이브러리 필요)
- 서버 재시작 후 프로젝트·릴리스·아티팩트 영속성 확인
- Vite 프로덕션 빌드
- JSON 스키마 v15 마이그레이션, 백업 검증/복원, 콘텐츠 해시 무결성
- 보안 헤더, 일반/로그인 속도 제한, 5 MB 기본 JSON 제한, 안정적인 오류 envelope
- GitHub Actions, Dockerfile, Compose, health/readiness/metrics

## 아직 “실차 완성”으로 주장할 수 없는 경계

이 저장소는 자율 자동차 개발 플랫폼의 실행 가능한 제품 MVP이며, 실제 자동차의 인증·양산 완료를 증명하지 않는다. 다음 항목은 코드만으로 완료할 수 없다.

1. FreeCAD/OpenCascade, OpenFOAM, CalculiX, CARLA 상용 수준 모델과 라이선스/연산 클러스터
2. ROS 2 로봇, PLC/OPC UA, 실제 센서·시험 셀과 현장 안전 검증
3. 공급사 가격·납기·품질 API, 공장 MES/ERP/PLM 데이터
4. 충돌·환경·내구 실물 시험과 공인 인증기관의 승인
5. 운영 규모에 맞춘 PostgreSQL, 객체 스토리지, 분산 큐와 시계열 인프라

외부 구성요소는 `server/engineProtocol.js`, `server/adapters.js`, `server/robotGateway.js`의 계약을 구현해 연결한다. 연결 후에는 동일한 승인·감사·아티팩트·릴리스 게이트를 그대로 통과해야 한다.
